# Student Management System

## About the Project
This is my first C programming project. It is a menu-driven Student Management System developed using the C programming language.

## Features
- Add student details
- Display all students
- Search students
- Find the student with the highest marks

## Technologies Used
- C Programming
- Structures
- Arrays
- String Handling
- Functions

## How to Run

1. Download the `sms.c` file.
2. Open it in VS Code.
3. Compile the program using GCC.
4. Run the executable.
